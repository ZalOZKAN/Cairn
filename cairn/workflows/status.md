# /status, Session Handoff

Generate a session summary for handoff to the next session.

## Output Format

### Session Summary, [timestamp]

**Completed:**
- List what was accomplished this session

**Current State:**
- What's the current status of the main task?
- Any partially completed work?

**Next Steps:**
- Prioritized list of what to do next session

**Blockers:**
- Anything blocking progress?

**Context to Remember:**
- Key decisions made
- Important file locations
- Any gotchas discovered

---
*Run this before ending every session. Paste into the next session's first message.*
